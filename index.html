Python for data analysis

Taught in French

A course I designed and teach for people who have never written a line of code. It ends where it should: a participant takes a raw CSV, Excel or SQL extract, cleans it, explores it, produces the statistics and the charts, and presents the conclusions without help.

How it is built

  • At most 45 minutes of lecture per session. The remaining two hours are spent at the keyboard. Beginners lose a language by watching it, not by writing it.
  • Installation is a double-click. A launcher decides on its own whether to install, update, or simply start, and places the conda environment outside any synchronised folder — a Drive or OneDrive directory silently corrupts it.
  • Every notebook exists twice, in a participant version and a solved version, both generated from one script so the two can never drift apart.
  • Reproducible work from session one: relative paths only, a fixed folder layout, and a naming convention — the habits that survive the course.
